Cara Mengaktifkan Direct Upload (Tanpa Cookie): 
1. ISI USER ID / GROUP ID ASLI KAMU:
   Buka profil Roblox kamu di browser, salin angka ID dari URL (contoh: roblox.com/users/123456789/profile), lalu tempel di kolom "Roblox User ID / Group ID".

2. ISI ROBLOX OPEN CLOUD API KEY:
   Buat di create.roblox.com/dashboard/credentials → pilih "Assets API" (Read & Write) → bagian IP isi 0.0.0.0/0 → tempel API Key di samping lalu klik "Simpan & Aktifkan Direct Upload Roblox".

3. MENDUKUNG SEMUA ASET (.rbxm, .ogg, .mp3, .wav, .png):
   Sistem otomatis mengemas file .rbxm / .rbxmx / animasi ke format Open Cloud (model/x-rbxm) sehingga langsung masuk ke inventori Roblox kamu tanpa memerlukan .ROBLOSECURITY!
Kamu bisa langsung mengisi Open Cloud API Key & User/Group ID di form sebelah kiri lalu klik Simpan, atau menaruhnya di tab Variables pada Railway (ROBLOX_API_KEY & ROBLOX_CREATOR_ID).
